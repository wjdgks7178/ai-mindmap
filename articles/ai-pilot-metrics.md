# 파일럿 지표 설계

> AI 파일럿의 성공 여부를 판단할 지표를 모델 품질·운영·도입·사업 가치로 나눠 기준선과 함께 미리 정하는 일.

## 쉽게 말하면
다이어트 전에 체중과 허리둘레를 재 두어야 효과를 안다. 지표 없이 시작한 파일럿은 "느낌상 좋았다"로 끝난다.

## 자세히
- **Google Cloud 생성형 AI KPI(2024-11)**: 5범주 — 모델 품질, 시스템 품질, 비즈니스 운영, 도입, 비즈니스 가치.
  - 모델 품질: 경계 있는 출력은 정밀도·재현율·F1, 경계 없는 출력은 LLM auto-rater(일관성·근거성·안전·지시 이행), 점별(0~5) 또는 쌍별(기준 모델 대비 승률). auto-rater는 사람 평가와 보정.
  - 운영 예: 컨테인먼트율, 평균 처리 시간, CSAT, 문서 처리 시간.
  - 도입: 활성 사용자 비율, 빈도, 세션당 질의, 좋아요/싫어요. 낮으면 인지 문제, 올랐다 떨어지면 성능 문제.
  - 가치: 도입 전 비용과 비교하고 구축·운영 총비용을 포함해 ROI 계산. 효율과 최종 목표를 혼동하지 않는다. 에이전트는 도구 선택 정확도처럼 다른 지표가 필요.
- **NIST AI RMF MEASURE**: 1.1 가장 큰 위험에 맞는 지표와 허용 성능 한계 정의, 측정하지 않을 위험도 문서화 / 1.2 드리프트를 위해 주기적 재평가 / 2.3 배포 유사 조건 테스트와 오탐·미탐 보고 / 2.4 운영 모니터링 / 4.2 사람 개입(override) 빈도 추적 / 4.3 기준선 대비 개선·악화 기록.
- 컨설팅 블로그의 "파일럿 87%가 기준선 없음" 같은 통계는 출처가 없어 인용하지 않는다.

## 예시
"송장 분류 정확도 92% 이상, 처리 시간 30% 단축, 사람 수정률 10% 이하, 8주 안에 달성 못 하면 중단"처럼 숫자와 기한을 적는다.
