# 같은 사실의 다양한 표현 학습

> 미세조정 데이터에 **같은 사실을 여러 방식으로 바꿔 쓴 버전**을 넣으면 모델이 새 사실을 더 잘 배운다는 관찰이다.

## 쉽게 말하면
같은 내용을 교과서·요약·문제 풀이·대화 등 여러 형태로 반복해 읽으면 더 잘 외워지는 것과 같다. 한 문장으로만 보면 오래 안 남는다.

## 자세히
(Ovadia 외 arXiv 2312.05934 PDF를 직접 읽었다.)
- **생성(논문)**: GPT-4에게 정보를 **완전히 유지하면서 표현만 바꾼** 변형을 만들게 했고, 매번 다른 시드로 다양성을 확보했다. 현재 사건 과제는 청크마다 **10개** 바꿔 쓰기를 만들어 미세조정에 사용.
- **효과(논문 Table 2)**: Mistral 7B 현재 사건 — FT-reg 0.504 → FT-par **0.588**. Llama2 7B 0.219 → 0.392. Orca2 7B 0.511 → 0.566. RAG와 결합했을 때(FT-par+RAG)는 Mistral 0.830, Llama2 0.520, Orca2 0.826으로 기본+RAG(0.875·0.585·0.876)보다 낮았다.
- **저자 결론(논문)**: 모델이 비지도 미세조정으로 새 사실을 배우기 어렵고, 같은 사실의 수많은 변형에 노출하면 **완화될 수 있다**.
- **주의(해석)**: 바꿔 쓴 데이터를 생성하는 GPT-4 비용·품질, 사실이 틀리게 바뀔 위험이 있다. 정보 보존 검증이 필요.
