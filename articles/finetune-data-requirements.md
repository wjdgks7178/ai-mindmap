# 파인튜닝 데이터 요건

> 파인튜닝에 필요한 데이터의 양·품질·형식·갱신 비용. 핵심 경험칙은 "많이보다 잘 고른 것"이다.

## 쉽게 말하면
요리사를 교육할 때 레시피 10만 장을 읽히기보다 완벽하게 만든 요리 1,000접시를 보여 주는 편이 낫다는 이야기다. 기본 실력(사전학습)은 이미 있고, 파인튜닝은 "우리 식 마무리"를 가르치는 단계이기 때문이다.

## 자세히
- **양**: LIMA 연구(2023, arXiv 2305.11206)는 65B LLaMA를 정제한 프롬프트·응답 **1,000개**만으로 지도학습해, 사람 평가에서 GPT-4와 같거나 더 선호된 비율 43%를 얻었다. 저자 주장: 지식은 거의 사전학습에서 오고, 정렬에는 소량의 고품질 데이터면 된다. (오래된 연구이며 일반 대화 형식 기준, 업무 특화에는 더 필요할 수 있음.)
- **품질**: 일관된 형식, 정답 검수, 중복·충돌 제거, 실제 입력 분포 반영, 엣지 케이스 포함. 틀린 예시는 그대로 학습된다.
- **분할**: 학습/검증/평가 세트를 나눈다. 평가 세트는 학습에 넣지 않는다.
- **효율적 학습(LoRA)**: 가중치 전체 대신 작은 어댑터만 학습. 논문(arXiv 2106.09685)은 GPT-3 175B 기준 학습 파라미터 약 1만 배, GPU 메모리 약 3배 절감이라 보고한다.
- **비용 감각**: 업체 블로그(denser.ai)는 LoRA/QLoRA 학습 1회 $50~500, 데이터 준비 $2,000~10,000, 지식 갱신 때마다 재학습 $500~5,000으로 추정한다(업체 추정치, 참고용). 사람 인건비가 데이터 준비에서 가장 크다.
- **한계**: 최신 사실을 넣는 용도로는 부적합(바뀔 때마다 재학습). 지식은 [RAG](#rag), 형식은 파인튜닝으로 나눈다([RAG+파인튜닝 조합](#hybrid-rag-finetune)).
- 플랫폼 정책: OpenAI는 파인튜닝 서비스를 신규 사용자에게 닫는 중(2026-11 문서). 오픈 모델+LoRA를 보는 경우가 늘 수 있다.

D --> E["LoRA 학습"]

## 예시
- 보험 약관 분류 모델: 상담 로그 800건을 정제해 라벨링(담당자 2명 교차 검수) → 학습 640 / 검증 80 / 평가 80. few-shot 대비 정확도와 토큰 비용을 비교해 결정.
