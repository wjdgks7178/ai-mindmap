# 점수 통과율 (Scoring Rate)

> 점수를 매기는 AI 도구의 공정성을 잴 때 쓰는 지표: **각 집단에서 전체 표본의 중앙값보다 높은 점수를 받은 사람의 비율**. 뉴욕시 LL144 규칙이 정의했다.

## 쉽게 말하면
시험 점수로 줄을 세울 때 "합격선"이 따로 없어도, 전체 중간 점수를 넘은 사람이 집단마다 몇 %인지는 셀 수 있다. 이 비율을 집단끼리 비교하면 점수 도구가 한쪽에 유리한지 보인다.

## 자세히
출처: DCWP 최종 규칙 채택 공고 원문(PDF, 본문 직접 확인, 2026-11-18).
- **정의(규칙)**: 범주 안에서 AEDT가 산출한 점수가 **표본의 중앙값을 넘는 개인의 비율**.
- **언제 쓰나**: 도구가 후보를 "선발·분류"하면 선발률을, 점수를 내면 점수 통과율을 쓴다(규칙 5-301(b)와 (c)).
- **계산 절차**: ①전체 지원자 점수의 중앙값 ②범주별 점수 통과율 ③[임팩트 레이쇼](#adverse-impact-ratio) = 범주 통과율 ÷ 최고 범주 통과율. 성별, 인종·민족, 교차 범주를 따로 계산하고, 미분류 인원 수를 표시한다.
- **공식 예시("culture fit" 점수, 규칙에 수록)**: 남성 92명 통과율 54.3%(1.00), 여성 76명 44.7%(0.82). 인종 범주에서 히스패닉 64.2%(1.00), 백인 37.5%(0.58), 흑인 50.0%(0.78), 아시아계 41.7%(0.65). 직접 계산: 44.7 ÷ 54.3 = 0.823.
- **왜 평균이 아닌 중앙값**: 규칙의 초기 제안과 달리 최종안은 중앙값 기준 통과율을 쓴다(검색 요약, 직접 확인한 것은 최종 정의). 극단값에 덜 민감한 지표라는 설명은 해석이다.
- **한계**: 중앙값을 기준선으로 삼아 실제 합격 컷오프와 다를 수 있다. 연속 점수의 분포 차이는 통과율 하나로는 다 담지 못한다.
- **2% 규칙**: 데이터의 2% 미만 범주는 비율 계산에서 제외 가능하나, 요약에 지원자 수와 통과율을 적어야 한다.

## 예시
```python
import pandas as pd
df = pd.DataFrame({"group": ["M"]*92 + ["F"]*76, "score": scores})
med = df.score.median()
rate = (df.score > med).groupby(df.group).mean()
ratio = rate / rate.max()
```
교육 활용: AI 평가 점수(영업 통화 평가 등)를 쓰는 직무 교육에서 "점수가 집단별로 어떻게 갈리나"를 직접 계산해 보는 실습으로 쓴다.

## 헷갈리는 것과 비교
| 개념 | 차이 |
|---|---|
| 점수 통과율 | 중앙값 초과 비율(점수형 도구) |
| 선발률 | 실제 다음 단계 진출 비율(분류형 도구) |
| [불리한 영향 비율](#adverse-impact-ratio) | 둘 중 어느 비율을 최고 집단으로 나눈 값 |
| 평균 점수 차이 | 크기를 보지만 중앙값 기준과 다름 |
