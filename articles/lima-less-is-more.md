# LIMA: 적은 데이터로 정렬

> **정제한 약 1,000개 예시만으로** 65B 모델을 미세조정해도 강한 응답 품질을 얻을 수 있다는 연구(Zhou 외, Meta·CMU 등, 2023). 정렬(alignment)에서 데이터 양보다 **질과 다양성**이 중요하다고 주장한다.

## 쉽게 말하면
수천 문제를 외우게 하는 대신 엄선한 1,000문제로 말투와 형식을 익히게 했더니 의외로 잘했다는 이야기다. 지식은 이미 사전학습에서 배웠으니 "어떤 식으로 답할지"만 가르치면 된다는 가설이다.

## 자세히
(LIMA 논문(arXiv 2305.11206) PDF를 직접 읽었다. 2023년 65B LLaMa 기준이며 사람 선호 평가이므로 지금 모델에 그대로 적용된다고 보장하지 않는다.)
- **가설(논문)**: **Superficial Alignment Hypothesis** — 모델의 지식과 능력은 사전학습에서 거의 다 배우고, 정렬은 사용자와 상호작용할 때의 **형식·스타일**을 가르치는 것이다.
- **데이터(논문)**: 정확히 **1,000개**(약 75만 토큰). Stack Exchange·wikiHow·Reddit 등 커뮤니티에서 **750개**를 질과 다양성 기준으로 선별, **250개**는 저자들이 직접 작성해 AI 비서 스타일을 일관되게 맞춤. 개발용 50개, 테스트 300개 프롬프트. wikiHow는 240,000개 글 중 카테고리 19개에서 200개 표본.
- **학습(논문)**: LLaMa 65B에 표준 지도 손실, RLHF 없음. 검증 perplexity가 생성 품질과 상관없어 5~10 에폭 사이에서 50개 개발 세트로 체크포인트를 **수동 선택**했다.
- **결과(논문, 사람 평가)**: LIMA 응답이 **GPT-4와 동등하거나 더 좋은 경우 43%**, Claude 46%, Bard 58%, DaVinci003 65%. 응답의 **88%**가 요구사항을 충족, 50%는 우수. 52,000개로 학습한 Alpaca 65B 재현보다 선호. 단 사람은 대체로 GPT-4·Claude·Bard 응답을 더 선호.
- **절제 실험(논문)**: 프롬프트 **다양성**을 같이 늘리지 않으면 데이터 양을 늘려도 수확 체감이 크고, 응답 **품질** 최적화는 큰 이득. 필터링한 Stack Exchange vs 필터 없는 2,000개에서 품질 점수 약 **0.5점** 차이. 대화 예시 0개로도 다중 턴 대화가 가능하고, **30개** 대화 체인을 추가하면 크게 개선.
- **한계(논문)**: 이런 예시를 만드는 **정신적 노력이 크고** 확장이 어렵다.
