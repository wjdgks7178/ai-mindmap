# llms.txt

> 웹사이트가 AI 에이전트에게 "읽을 만한 핵심 페이지"를 알려 주려고 사이트 루트에 두는 마크다운 안내 파일 제안이다(Jeremy Howard, 2024-09-03). 차단용이 아니라 안내용이다.

## 쉽게 말하면
건물 로비의 층별 안내도다. 방문객(AI)이 모든 방을 뒤지지 않고 안내도에서 필요한 방만 찾아가게 한다. 출입 금지 표지판(robots.txt)과는 목적이 다르다.

## 자세히
(llmstxt.org 제안 페이지를 직접 열어 확인. 페이지는 v2, 2026-08-10 수정 표시.)
- **목적**: 에이전트가 작은 파일을 먼저 읽고 필요할 때만 세부 페이지를 가져오게 하는 큐레이션된 개요. 링크 대상은 마크다운판 페이지 등 LLM 친화 콘텐츠.
- **위치**: 사이트 루트 `/llms.txt` 또는 하위 경로(그 아래 페이지에 적용). 여러 파일이 있으면 가장 구체적인 것을 사용.
- **형식(마크다운)**: ① (선택) BOM ② **H1 사이트·프로젝트 이름(유일한 필수 요소)** ③ 인용 블록 요약 ④ 제목 없는 상세 문단·목록 ⑤ H2 섹션의 링크 목록(`[이름](URL): 설명`) ⑥ 관례상 "Optional" 섹션(문맥이 부족할 때 건너뛸 링크).
- **관련 제안**: 페이지의 마크다운판을 같은 URL에 `.md`를 붙여 제공, `rel="alternate" type="text/markdown"` 또는 `Link` 헤더로 연결.
- **다른 파일과 비교(제안 페이지 설명)**: robots.txt는 허용 가능한 자동 접근, llms.txt는 에이전트가 사용자를 돕는 동안 필요한 추론용 맥락(학습이 아님). sitemap.xml은 색인 대상 전체 목록이라 길고 LLM용 버전을 빠뜨리는 반면 llms.txt는 짧고 큐레이션된다.
- **주의**: 표준으로 확정된 것이 아니라 **제안**이며, 모든 AI 서비스가 읽는다는 보장은 없다(이번에 지원 현황은 확인하지 않았다). `llms-full.txt`는 이 페이지에서 확인되지 않았다.

## 예시
```markdown
# 우리 문서 사이트
> 제품 사용 가이드 모음

## 시작하기
- [설치](https://example.com/install.md): 설치 방법
## Optional
- [릴리스 노트](https://example.com/changelog.md)
```
- 교육 활용: 자기 회사 문서 사이트의 llms.txt를 직접 작성해 보기.

## 헷갈리는 것과 비교
| 파일 | 역할 |
|---|---|
| robots.txt | 크롤러 접근 허용·금지 요청 |
| sitemap.xml | 색인할 전체 페이지 목록 |
| llms.txt | AI가 읽을 핵심 안내(큐레이션) |
